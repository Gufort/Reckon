## Посетители синтаксического дерева программы

см. [общее описание задания](http://gitlab.mmcs.sfedu.ru/mmcs/compilers-fiit/-/wikis/%D0%92%D0%B8%D0%B7%D0%B8%D1%82%D0%BE%D1%80%D1%8B_%D0%BF%D0%BE_%D1%81%D0%B8%D0%BD%D1%82%D0%B0%D0%BA%D1%81%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%BC%D1%83_%D0%B4%D0%B5%D1%80%D0%B5%D0%B2%D1%83)

### вариант задания

Язык: **Reckon** — декларативный, реактивный язык вычислений для онлайн-таблиц. Программа представляет собой книгу (workbook): набор определений ячеек и именованных формул. Каждая ячейка — это формула, граф зависимостей — сама программа.

### сборка

Этот проект использует:

* пакет GPLex для генерации файла `Task/SimpleLex.cs`.
* пакет GPPG для генерации файла `Task/SimpleYacc.cs`.

Для сборки запустите:

```
dotnet tool run GPLEX /unicode /out:Task\SimpleLex.cs Task\SimpleLex.lex
dotnet tool run GPPG /no-lines /gplex /out:Task\SimpleYacc.cs Task\SimpleYacc.y
```

### классы посетителей

В папке `Task/Visitors` собраны классы для обхода дерева программы:

1. **Visitor.cs** — абстрактный базовый класс посетителя с методами `VisitXxxNode`.
2. **AutoVisitor.cs** — стандартный рекурсивный обход всех узлов.
3. **PrettyPrintVisitor.cs** — вывод синтаксического дерева в текстовом виде.
4. **DependencyExtractor.cs** — извлечение зависимостей для каждой ячейки.
5. **CycleDetector.cs** — обнаружение циклических зависимостей.
6. **ReferenceChecker.cs** — проверка, что все ссылки определены.
7. **ConstantFolder.cs** — свёртка константных арифметических выражений.

### задания

1. Реализовать `DependencyExtractor`. Для каждого определения ячейки собрать множество адресов, от которых она зависит.
2. Реализовать `CycleDetector`. Построить граф зависимостей и обнаружить циклы.
3. Реализовать `ReferenceChecker`. Проверить, что все упомянутые в формулах ячейки определены.
4. Реализовать `ConstantFolder`. Сворачивать константные арифметические подвыражения.
5. Написать модульные тесты для каждого посетителя.
