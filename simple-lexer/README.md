## Задание 1. Лексический анализатор языка Reckon (ручная реализация)

**Reckon** — это декларативный, реактивный язык вычислений на основе ячеек для
совместных онлайн-таблиц. Программа Reckon — это *рабочая книга*: набор
именованных ячеек и формул, каждая из которых определяется выражением.
Язык не содержит операторов и побочных эффектов.

Более подробное описание языка — в вики-статье (раздел «Reckon 0.1 — Calculator»).

### Цель

Разработать лексический анализатор (вручную, посимвольно) для языка Reckon версии 0.1.
Анализатор принимает поток символов и разбивает его на токены.

### Теория

Лексический анализатор (лексер, сканер) — первая фаза компилятора. Он читает
входной поток символов и группирует их в осмысленные последовательности —
*лексемы* (токены). Каждый токен имеет тип (например, `NUMBER`, `PLUS`, `CELLREF`)
и, возможно, значение (числовое, строковое и т.д.).

Лексер должен:
* Пропускать пробельные символы.
* Распознавать ключевые слова, идентификаторы, числа, строки, операторы.
* Пропускать комментарии.
* Сообщать об ошибках при встрече недопустимых символов.

### Задание

Реализовать класс `Lexer` в пространстве имён `Reckon`. Публичный интерфейс:

* `LexKind` — тип текущей лексемы (enum `Tok`)
* `LexText` — текст текущей лексемы
* `LexValue` — значение лексемы (int для чисел, string для строк, bool для TRUE/FALSE)
* `LexRow`, `LexCol` — строка и столбец начала лексемы
* `NextLexem()` — переход к следующей лексеме
* конструктор, принимающий `System.IO.TextReader`

Типы токенов (`enum Tok`):

| Токен | Пример | Описание |
|-------|--------|----------|
| `NUMBER` | `42`, `3.14` | Целые и десятичные числа |
| `STRING` | `"hello"` | Строковые литералы с экранированием `\"`, `\\`, `\n`, `\t` |
| `BOOL` | `TRUE`, `FALSE` | Логические константы |
| `ERROR` | `#DIV/0!`, `#N/A` | Литералы ошибок |
| `CELLREF` | `A1`, `$A$1`, `A$1`, `$A1` | Ссылки на ячейки |
| `COLREF` | `@A`, `@AB` | Ссылки на весь столбец |
| `ROWREF` | `@1`, `@42` | Ссылки на всю строку |
| `FUNCNAME` | `SUM`, `IF`, `AVG` | Имена функций (все буквы заглавные) |
| `NAME` | `total`, `price` | Имена ячеек и формул (строчные/смешанные) |
| `ASSIGN` | `:=` | Присваивание |
| `PLUS` | `+` | Сложение |
| `MINUS` | `-` | Вычитание |
| `MULT` | `*` | Умножение |
| `DIV` | `/` | Деление |
| `POW` | `^` | Возведение в степень |
| `CONCAT` | `&` | Конкатенация строк |
| `EQ` | `=` | Равно |
| `NEQ` | `<>` | Не равно |
| `LT` | `<` | Меньше |
| `GT` | `>` | Больше |
| `LEQ` | `<=` | Меньше или равно |
| `GEQ` | `>=` | Больше или равно |
| `LPAREN` | `(` | Открывающая скобка |
| `RPAREN` | `)` | Закрывающая скобка |
| `COMMA` | `,` | Запятая |
| `COLON` | `:` | Двоеточие (диапазон) |
| `BANG` | `!` | Восклицательный знак (ссылка на лист) |
| `ARROW` | `->` | Стрелка |
| `EOF` | — | Конец файла |

### Примеры

Вход:
```
A1 := 10
A2 := $A$1 + SUM(A1:A2) -- комментарий
{- вложенный {- комментарий -} -}
result := IF(A1 > 0, "ok", #DIV/0!)
```

Ожидаемые токены:
```
CELLREF(A1), ASSIGN, NUMBER(10),
CELLREF(A2), ASSIGN, CELLREF($A$1), PLUS, FUNCNAME(SUM),
LPAREN, CELLREF(A1), COLON, CELLREF(A2), RPAREN,
NAME(result), ASSIGN, FUNCNAME(IF), LPAREN,
CELLREF(A1), GT, NUMBER(0), COMMA, STRING("ok"),
COMMA, ERROR(#DIV/0!), RPAREN, EOF
```

### Критерии оценки

| Критерий | Баллы |
|----------|-------|
| Числа, имена, ключевые слова TRUE/FALSE, различие FUNCNAME/CELLREF/NAME | 1 |
| Операторы: + - * / ^ & := = <> < > <= >= ( ) , : ! -> | 1 |
| Комментарии: -- до конца строки, {- -} с поддержкой вложенности | 1 |
| Строки с экранированием, литералы ошибок | 1 |
| Ссылки на ячейки ($A$1, A$1, $A1, A1), COLREF (@A), ROWREF (@1) | 1 |
| Полная программа (все типы токенов) | 1 |
| **Итого** | **6** |
