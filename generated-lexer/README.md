# Задание 2: Генерация лексера (GPLEX) для Reckon

## Цель
Изучить принципы автоматической генерации лексера с помощью инструмента GPLEX.
Разработать GPLEX-спецификацию для токенизации языка Reckon R0.1.

## Теория
GPLEX (Gardens Point Lexer) — генератор лексеров для платформы .NET.
Он принимает на вход файл спецификации (`.lex`), содержащий регулярные
выражения и действия на C#, и генерирует код лексера на C#.

Основные элементы GPLEX-спецификации:
- **Определения** — имена для регулярных выражений (например, `Digit [0-9]`)
- **Правила** — шаблоны и действия в формате `шаблон { действие }`
- **Начальные условия** — состояния лексера (например, `%x COMMENT` для
  вложенных блок-комментариев)
- **Пользовательский код** — код на C# после второго `%%`

Принцип работы:
1. Лексер читает входной поток символов
2. Сопоставляет префикс входа с каждым шаблоном
3. Выбирает шаблон с наибольшей длиной совпадения
4. При равенстве длин выбирает первый по порядку шаблон
5. Выполняет связанное с шаблоном действие

## Задание
Разработать GPLEX-спецификацию для языка Reckon R0.1.
Лексер должен распознавать следующие токены:

| Токен | Описание | Примеры |
|-------|----------|---------|
| NUMBER | Целые и вещественные числа | `10`, `3.14` |
| STRING | Строки в кавычках с экранированием | `"hello"`, `"say \"hi\""` |
| BOOL | Булевы литералы | `TRUE`, `FALSE` |
| ERROR | Литералы ошибок | `#DIV/0!`, `#N/A`, `#VALUE!`, `#REF!`, `#NAME?`, `#NUM!`, `#NULL!` |
| CELLREF | Ссылки на ячейки | `A1`, `$A$1`, `A$1`, `$A1` |
| COLREF | Ссылки на столбцы | `@A`, `@AB` |
| ROWREF | Ссылки на строки | `@1`, `@42` |
| FUNCNAME | Имена функций (только заглавные) | `SUM`, `IF`, `MAP` |
| NAME | Имена (строчные/смешанные) | `total`, `tax`, `myValue` |
| ASSIGN | Присваивание | `:=` |
| PLUS, MINUS, MULT, DIV, POW, CONCAT | Арифметические операторы | `+`, `-`, `*`, `/`, `^`, `&` |
| EQ, NEQ, LT, GT, LEQ, GEQ | Операторы сравнения | `=`, `<>`, `<`, `>`, `<=`, `>=` |
| LPAREN, RPAREN | Скобки | `(`, `)` |
| COMMA | Запятая | `,` |
| COLON | Двоеточие | `:` |
| BANG | Восклицательный знак | `!` |
| ARROW | Стрелка | `->` |

Также реализовать:
- Однострочные комментарии (`--` до конца строки)
- Вложенные блок-комментарии (`{- ... -}` с подсчётом глубины)
- Подсчёт статистики: количество идентификаторов, чисел, строк,
  ключевых слов, ссылок, ошибок, строк, сумма целых чисел

## Примеры

Вход:
```
A1 := 10 + 20
A2 := $A$1 * 3
A3 := SUM(A1:A2) / 2
total := A3 + 1
```

Ожидаемые токены: CELLREF(A1), ASSIGN, NUMBER(10), PLUS, NUMBER(20),
CELLREF(A2), ASSIGN, CELLREF($A$1), MULT, NUMBER(3),
CELLREF(A3), ASSIGN, FUNCNAME(SUM), LPAREN, CELLREF(A1), COLON,
CELLREF(A2), RPAREN, DIV, NUMBER(2),
NAME(total), ASSIGN, CELLREF(A3), PLUS, NUMBER(1), EOF

Статистика: cellRefCount=6, numCount=4, funcCount=1, nameCount=1,
sumInt=36 (10+20+3+2+1)
